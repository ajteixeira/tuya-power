# Objetivo
Quer criar um site web, pode ser em python, que me permita gerir todos os dispositivos que tenho em casa. Estes dispositivos estão ligados à app da tuya. Tenho conta tuya de developer.

# Funcionalidades
1. Descarregar o histórico para uma base de dados local, para não perder o detalhe. A tuya guarda apenas uma peque parte do registo histórico e eu quer aproveitar todo o histórico disponivel. Prever uma descarga de dados, não duplicada pelo menos 1x dia.
2. Acesso online ao estado do dispositivo
3. Permitir ligar, desligar e ajustar o dispositivo
4. Permitir configurar o dispositivo
5. Permitir consultar o seu histórico de registos, consumos, log
